# Contributing

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sxproto/sxpb-js.git
   cd sxpb-js
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

   *Note: This command generates the `package-lock.json` file. This file is ignored by git and should not be committed.*

## Building

To build the project (compile TypeScript to JavaScript):

```bash
npm run build
```

## Testing

To run the test suite:

```bash
npm test
```

## Linting

To run the linter:

```bash
npm run lint
```
